# About

This lightweight blockchain wallet is a browser extension that is supported on all chromium web browsers. To use the wallet yourself, 
clone the repo, then go into your browser and in the url go to 'chrome://extensions/', enable developer mode, click 'load unpacked', and add this project. 

## Features

:white_check_mark: Supports all EVM networks <br /> 
:white_check_mark: Add custom ERC20 tokens  <br /> 
:white_check_mark: Import other wallets  <br /> 
:white_check_mark: Buy assets using moonpay  <br />
